## 一、为什么停这五天不是坏事

宁宁 10-17 凌晨自己说的：素材买了一堆，自己拼家具，**每次都觉得很怪**，所以停了五天，想重画一版。

怪的原因不在手，在**没有共用的底**：一批素材一个色系、一种描线习惯，拼在一块，气就不顺。

**结论：先定画风，再画东西。** 这一页就是那个"底"。

## 二、现在屋子里正在用的颜色

（从 `house.html` / `base.json` 抄的，2026-10-13 那一版）

### 描线 —— 像素画不用纯黑

| 名字 | 值 | 用途 |
|---|---|---|
| `INK_HARD` | `#221f33` | 最硬，轮廓 |
| `INK` | `#2f2b45` | 中间，用得最多 |
| `INK_SOFT` | `#403a5c` | 最软，远一点的边 |
| `FLOOR_INK` | `rgba(92,52,32,.55)` | 地板缝（深棕，地板这块不用蓝紫） |

> 规矩：**别用纯黑描边。** 纯黑又硬又脏；暗蓝紫一描，整张画会"透"。

### 框（相框那一圈）

| 名字 | 值 |
|---|---|
| `FRAME_EDGE` | `#2f2b45` |
| `FRAME_MID` | `#f2eee3` |
| `FRAME_HI` | `#ffffff` |
| `FRAME_IN` | `#4a6d99` |
| `FRAME_SEAM` | `#cfc7b6` |

### 墙和地（一间一个色，写在 `base.json` 的 `wallTint` / `floorTint`）

- 客厅墙：米黄 `#dcd2bc`
- 客厅地：赭红 `#ad6a42`，缝是深棕，横 24 竖 64
- **只给一个颜色**，`house.html` 自己算深浅：墙上下差 11%，地板差 14%
- 护墙角跟着 `wallTint` 走：上沿深 5%，下沿深 12%

## 三、画墙纸 / 地板 / 家具，要守的四条

1. **尺寸**：`32×32` 或 `64×64` 的正方形，PNG
2. **无缝**：四边得能接上 —— 画的时候上下、左右对齐（放 `tiles/`）
3. **描线**：用第二节那族深蓝紫，别用纯黑
4. **一套之内亮部方向要一致**（先假设光从左上来），不然拼起来会打架
